While Listening to Albums 听专辑的时候我在想些什么

Full-stack music journaling app · May 2025 – Present 全栈音乐日记 Web 应用 · 2025 年 5 月至今

A web app for logging the albums you listen to and writing listening notes with 1–10 decimal ratings: a React + Vite SPA on an Express REST API with Mongoose models. One search queries the Spotify Web API and NetEase Cloud Music concurrently — the Node.js backend drives a Python crawler through a JSON CLI in a child process — merges cross-platform duplicates by normalized title, artist, and year, and still returns partial results with a per-source status when either source fails. Containerized with a multi-stage Dockerfile and Docker Compose, and tested with Mocha/Chai on an in-memory MongoDB. 一个用来记录听过的专辑、写听歌笔记的 Web 应用，评分为 1–10 分并支持小数：前端是 React + Vite 单页应用， 后端是 Express REST API 与 Mongoose 数据模型。一次搜索会同时查询 Spotify Web API 和网易云音乐——Node.js 后端通过子进程里的 JSON CLI 调用 Python 爬虫——再按标准化后的标题、艺人和年份合并两个平台上的同一张专辑； 任何一个来源失败时，仍会返回另一个来源的结果并附上每个来源的状态。使用多阶段 Dockerfile 与 Docker Compose 容器化，并用 Mocha/Chai 在内存 MongoDB 上测试。
